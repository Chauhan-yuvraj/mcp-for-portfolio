## 🚀 Projects & Open Source

### 💻 Key Technical Projects

**1. AI Portfolio Agent (MCP-Powered)**

- **Tech:** Next.js, TypeScript, Python (FastAPI + FastMCP), Gemini 2.0 Flash.
- **Overview:** The very website you are looking at! A next-gen portfolio featuring an embedded AI agent.
- **Architecture:** Built using the **Model Context Protocol (MCP)**. The Frontend (Next.js) communicates with a Python backend (FastAPI), which spawns an MCP Server.
- **Key Features:**
  - **Tool Calling:** The AI autonomously decides which "tool" to use (reading Bio, Experience, or Projects) based on the user's query.
  - **Single Source of Truth:** Data is fetched dynamically from modular Markdown files, eliminating hallucinations.
  - **Persistent Memory:** Remembers user details (like name) across sessions using LocalStorage.

**2. High-Performance File Explorer**

- **Tech:** React, Wails, TailwindCSS.
- **Achievement:** Achieved **80x faster search** compared to Windows Explorer using virtualization.

**3. Drone Management System**

- **Tech:** Node.js, Socket.io, Mapbox.
- **Achievement:** Real-time flight telemetry with **zero latency**.
